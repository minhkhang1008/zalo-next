## 4. Gotchas learned
- Codex wrapper: `scripts/codex.sh task --write --cwd <worktree> --prompt-file <brief>`; one writer per file;
  Codex often stops when a needed file is outside scope — widen scope explicitly and rerun.
- Merging feature branches into the test branch conflicts in gui.rs / worker.rs / session.rs / messages.rs /
  chat.rs / store.rs because every feature adds GuiEvent variants, WorkerCmd variants and ChatMessage fields;
  resolve by keeping both sides. `ActiveCallOverlay` now has `is_connected` (app-lock) — new literals need it.
- `session.rs` has one `http_client_builder(proxy)`; add `.cookie_provider(jar)` where a session client is needed.
- Never `cargo fmt`; rustfmt only clean files. Many big files (gui.rs, worker.rs, modals.rs, messages.rs) are
  not rustfmt-clean.
- Privacy: never put message content or ids in briefs; read local caches by key shape only.
